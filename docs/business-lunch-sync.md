# Автоматическое обновление названий бизнес-ланча

Названия сетов и блюд берутся по ID напрямую из iikoServer
(`/resto/api/v2/entities/products/list`). Это обходит задержку выгрузки
из iikoOffice в iiko Cloud. Состав внешнего меню «Сайт», цены, группы и ID
для заказа остаются из `/api/2/menu/by_id`.

Подключение включается серверными переменными `IIKO_SERVER_URL`,
`IIKO_SERVER_LOGIN`, `IIKO_SERVER_PASSWORD_SHA1` (SHA-1 пароля для протокола
iikoServer; это секрет, эквивалентный паролю). Секреты хранятся в серверном
окружении Vercel, не попадают в клиентский JavaScript. Передача только по HTTPS,
перенаправления запрещены. Сессия API закрывается после каждого чтения,
включая ошибки. При изменении пароля нужно обновить серверный секрет.

Без настроенного `IIKO_SERVER_URL` используется прежний Cloud-источник
`/api/1/nomenclature`, который зависит от выгрузки iiko. При настроенном прямом
подключении ошибка сервера НЕ вызывает откат к устаревшим именам из Cloud.

Открытая страница меню получает `/api/business-lunch` при загрузке,
раз в 60 секунд и при возвращении на вкладку. Ответ не кешируется браузером,
CDN или прокси. Сервер хранит справочник названий максимум 60 секунд;
одновременные запросы на одном сервере объединяются.

При нормальной связи название появится на активной странице примерно
за 1–2 минуты после сохранения на iikoServer. Пересборка сайта,
сброс кэша и ручные правила для отдельных блюд больше не нужны.
Добавление новых блюд в состав внешнего меню и изменение цен по-прежнему
зависят от его выгрузки: прямое подключение обновляет только названия.

Пометка «БЕЗ ГАРНИРА» управляет выбором гарнира. Её можно добавлять
и удалять в iiko. Уже выбранное блюдо сохраняется при переименовании;
недоступная или удалённая опция больше не считается допустимым выбором.
Уже добавленные в корзину позиции эта синхронизация не переписывает.

При сбое запроса браузер сохраняет последнее успешно полученное меню
и повторяет запрос через минуту. Ошибка справочника в live-эндпоинте
возвращает 503, а не пустое меню с успешным статусом.

Проверка: `npm test -- lib/iiko lib/menu app/api/business-lunch`.
Для диагностики запросить `/api/business-lunch`: статус 200,
`Cache-Control: no-store, max-age=0`, актуальные имена в `categories`.
Заголовок `X-Menu-Names-Source: iiko-server` подтверждает прямой источник.
Афиша недели является отдельным изображением и не меняется от переименований.
