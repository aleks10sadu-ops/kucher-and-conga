## Проверки

- `npm run build`, `npx tsc --noEmit`, `git diff --check` — без ошибок.
- Сопоставление JSON: все семь пунктов программы, три этапа и четыре подписи галереи совпадают с исходником; обе цены сохранены.
- Браузер: ширины 360, 390, 768, 1366 и 1440 px без горизонтального переполнения; загрузка изображений, три телефонных CTA, клавиатурный фокус, переключение снега и сохранение выключенного состояния после перезагрузки.
- Увеличение базового текста до 200% проверено на 360 и 1440 px временным CSS-правилом: границы текста и действий остаются в экране. Проверочное правило удалено. Это проверка увеличения текста, не браузерного zoom.
- Метатег `noindex, nofollow` проверен в браузере; маршрут отсутствует в сгенерированном sitemap.

Системная эмуляция `prefers-reduced-motion` недоступна в используемом браузерном инструменте; соответствующая ветка реализована, но не проверена переключением ОС. Ручное выключение движения проверено по вычисленному `animation-name: none`.

Скриншоты новой версии имеют `v2` в названии и находятся в `screenshots/`. Старые скриншоты относятся к предыдущей версии. Полностраничная склейка встроенного браузера давала повторы фрагментов; общий вид сохранён одним кадром с высоким viewport.
