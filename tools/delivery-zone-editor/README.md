# Локальный редактор зон доставки

Самостоятельная Flask-страница для рисования и настройки зон доставки на карте. Редактор не читает и не изменяет файлы основного сайта.

## Запуск

```powershell
cd "tools\delivery-zone-editor"
py -m pip install -r requirements.txt
py app.py
```

Откройте [http://127.0.0.1:5123](http://127.0.0.1:5123).

## Как работать

1. Перетащите белые маркеры выбранного исходного контура или измените координаты справа. Карта автоматически пересчитает вырезы. Пунктиром показан редактируемый исходный контур, заливкой — фактическая территория доставки.
2. «Нарисовать» создаёт зону с приоритетом над остальными; двойной щелчок завершает полигон. Новая зона точно вырезает пересечения из прежних тарифных областей. Чтобы поднять существующую зону, выберите её и нажмите «Вытеснить пересечения». Для старых файлов без явного приоритета сохраняется правило меньшей площади, при равной площади — порядка в файле. «Проверить» показывает тариф для точки; результат пересчитывается при изменении зон.
3. «Импорт» загружает `.geojson`/`.json` с `FeatureCollection` и полигонами, а также JSON-ответ Яндекс Vendor с массивом `coordinates` (`lt`/`lg`). После чтения файла редактор покажет список найденных зон: отметьте только нужные и подтвердите импорт. Выбранные зоны заменят текущий набор, а метки и линии из смешанного GeoJSON будут пропущены.
4. «Сохранить черновик» записывает исходные контуры и приоритеты только в `data/delivery-zones.geojson`, создавая резервную копию в `backups/`. Перемещение или удаление вытесняющей зоны восстанавливает освободившиеся территории. «Отменить» возвращает весь последний сохранённый набор.
5. «Экспорт с вырезами» скачивает один GeoJSON со всеми фактическими зонами, включая несохранённые изменения. Пересечения площадей устранены, все объекты имеют тип `Polygon`. Расчёт выполняется локально через Shapely; его ошибка блокирует экспорт устаревшей геометрии.

## Вырезы и сохранение границ

Вырезание использует геометрическую разность, без сглаживания, буферов и искусственных соединительных полос. Границы вне пересечений не сдвигаются. Скрытие зоны влияет только на отображение, а не на тарифы и экспорт. Список влияния выбранной зоны показывает изменения фактических тарифных областей: СНТ Дружба 6 вытесняет 300 и 400 ₽, но не затрагивает область тарифа 500 ₽.

Вложенный участок становится внутренним кольцом одного `Polygon`. Если новая зона полностью разрезает прежнюю на отдельные участки, в редакторе остаётся одна тарифная запись с пометкой о числе участков. В общем файле её части идут отдельными `Polygon` с одинаковыми условиями и уникальными идентификаторами; `MultiPolygon` не экспортируется. Полностью вытесненная зона сохраняется в черновике и восстанавливается при удалении перекрывшей её зоны.

Самопересечения исправляются для расчёта с явным сообщением в блоке «Вырезы готовы». Реальные площадные части сохраняются. Отдельный фрагмент меньше 10 м² удаляется только тогда, когда он появился при исправлении самопересечения и составляет меньше 0,001% исходной зоны. Исходный контур остаётся доступен для ручного исправления. В текущей зоне 300 ₽ такая проверка убирает техническую петлю примерно 2 м².

Экспорт содержит `deliveryZoneEditor.sources` с исходными контурами и приоритетами. Повторный импорт этого файла в редактор восстанавливает логические зоны без размножения их частей. Обычные внешние `Polygon` с внутренними кольцами также импортируются без потери вырезов. Локальный файл черновика хранит исходники; для передачи вырезов используйте именно кнопку экспорта.

Совместимость: подтверждено, что импортёр Vendor отклоняет `MultiPolygon`. Новый экспорт использует только `Polygon`, но приём внутренних колец, нескольких объектов и тарифных свойств самим Vendor ещё необходимо проверить в его кабинете. Не следует считать локальную проверку успешной загрузкой в Vendor.

## Формат GeoJSON

Каждая зона — `Feature` с геометрией `Polygon`. Координаты записываются по стандарту GeoJSON в порядке `[долгота, широта]`.

Поддерживаемые свойства:

```json
{
  "id": 1,
  "name": "Бесплатная доставка",
  "price": 0,
  "minOrder": 1000,
  "color": "#22c55e",
  "opacity": 0.3
}
```

Необязательное целое свойство `priority` задаёт явный приоритет: большее значение вытесняет меньшее. Новая зона получает значение выше существующих. При отсутствии свойства используется прежний порядок по площади.

Если порт 5123 занят старым запущенным процессом, обновлённую версию можно запустить отдельно:

```powershell
$env:FLASK_PORT = '5124'
.venv/Scripts/python.exe app.py
```

В этом случае откройте [http://127.0.0.1:5124](http://127.0.0.1:5124).

Поиск адресов использует публичный Nominatim, а карта — тайлы OpenStreetMap, поэтому для них требуется подключение к интернету. Рисование, импорт, сохранение черновика и экспорт выполняются локально.

## Как забрать существующие зоны из Яндекс Vendor

В личном кабинете нет штатной кнопки экспорта. Откройте страницу нужного ресторана и раздел «Зоны доставки», затем:

1. Нажмите `F12` → `Network` (Сеть) → фильтр `Fetch/XHR`.
2. Обновите страницу и в строке фильтра введите `zone`.
3. Откройте запрос, в ответе которого есть `coordinates` и точки `lt`/`lg`.
4. На вкладке `Response` скопируйте весь JSON в файл с расширением `.json`.
5. Загрузите файл кнопкой «Импорт» в локальном редакторе.

Официальный интеграционный метод зон Яндекс Еды доступен только по подписке; инструкция выше использует только данные своего авторизованного кабинета.
